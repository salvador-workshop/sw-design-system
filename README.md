# sw-components

SW's design system / component library

## Overview

Wrapper over ([Geist-UI v2.3.8](https://github.com/geist-org/geist-ui/releases))

## Development

MacOS Ventura 13.2.1

### Installation

```
npm install
```

### Running storybook

```
npm run storybook
```

Launches storybook, for a deep dive into components.
